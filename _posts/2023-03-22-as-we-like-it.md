如果喜歡看低科技、慢活、科幻元素、反串喜劇、向女性致敬，或是莎翁經典著作的粉絲們，這部以多元面向所拍攝的《揭大歡喜 As We Like It》電影會滿對你的味！

-   劇名｜揭大歡喜 As We Like It
-   導演｜陳宏一、魏瑛娟
-   上映｜2021-03-12
-   時間｜107分鐘
-   演員｜郭雪芙、謝沛恩、夏朧、陸明君、黃瀞怡（小薰）、曹蘭、鍾欣凌

許久沒有進戲院，上次進戲院好像是三個月前，剛好有朋友當主揪決定一起進戲院支持國片，尤其是這台版寶塚，台灣首部全由女性演出的電影，如此特別的元素當然要來朝聖囉。

本部電影《揭大歡喜 As We Like It》改編自莎士比亞的四大喜劇之一，分別是《仲夏夜之夢》、《威尼斯商人》、《第十二夜》以及《皆大歡喜》。

本片，以揭開的「揭」作為致敬，也是揭開當時不准女性演員上台演出的父權面紗。導演陳宏一、魏瑛娟讓全片角色都由女性擔綱演出，是否很難想像甜美女神郭雪芙、靈氣動人的謝沛恩、時尚冷豔的陸明君、喜感始祖的曹蘭等，紛紛以短髮平頭、束胸、豪邁姿態造型出演「真男人」？看他們如何在C門町這個無網路的烏托邦世界展開幻奇旅程。

我先說，一開始很不習慣，覺得有點違和，只是看著看著就跟著掉進劇情裡。不得不說她們「氣口」很驚艷！像是措辭、不刻意的嗓音、走路的樣態，打破我對她們的想像，如果說貧窮會限制人的想像，那麼性別是不是也會限制了人對生活的想像，還是說凡事不設限，偶爾來場冒險，不以世俗慣有的邏輯，才能有超出預期中的驚喜。

// 前面廢話有點多，先來簡介一下劇情 //

《揭大歡喜 As We Like It》描述：在歐洲念書的羅琳（郭雪芙飾演）相偕堂妹羅蕾蕾（夏朧Camille Chalons 飾演）回國處理失蹤長達七年父親的財產問題，於是在Ｃ門町展開尋父之旅。

黑輪（謝沛恩飾演）在一場格鬥賽上對羅琳一見鐘情，羅琳不願被輕易追求，從《梁祝》得到靈感，易裝假扮雙胞胎哥哥羅斯福，與黑輪大玩鳳求凰。黑輪為了找尋真愛陪羅斯福尋找父親，最終贏得美人心。

黑輪與哥哥歐立華（陸明君飾演）為Ｃ門町老家都更反目，哥哥信仰現代科技價值，弟弟崇尚簡單生活，歐立華成熟世故但遇上羅蕾蕾，全然投降，直接成了愛情奴隸。

故事以此二對姊妹與兄弟的愛情喜劇為主，輔以當代城市與無網路特區的對壘，重新思考生活的價值與幸福的意義。

### 兩位導演的經歷

這兩位導演的導戲經歷，在我觀影生涯的有著非常不錯的評價，尤其是那些愛看電影的文青圈圈中，以如果看完以下簡介，一定會喚起你的回憶，像是《消失打看》、《相愛的七種設計》，記得以前在雜誌週刊上班時，旁邊的同事曾連續數週都在討論這幾部劇情，好像是文藝青年必備的標配。

-   陳宏一，台大哲學系學士，電影《自畫像》獲Granada影展最佳影片金獎，入選鹿特丹國際影展。《相愛的七種設計》獲休士頓影展最佳劇情片。《消失打看》獲台北電影獎最佳導演與瑞士Fribourg影展評審團獎。《花吃了那女孩》獲金馬獎最佳造型設計。
-   魏瑛娟，台大外文系學士，紐約大學 (NYU) 教育劇場碩士。莎妹劇團創辦人，創作社劇團創始團員，自1985開始劇場創作，已編導發表作品近四十齣。現任紅色製作有限公司總監。監製電影有《相愛的七種設計》、《消失打看》、《花吃了那女孩》等。

整體來說，揭大歡喜有些黑色喜劇、無厘頭、舞台劇的演法，領著你稍稍抽離現實生活，腦海中飄著的畫面可能是穿越時空、性別轉換，總之呢，就是喚起心中那非主流、很鬧、貪趣，抑或是崇尚文字溫度，以手寫文字傳遞資訊的搖滾靈魂。
